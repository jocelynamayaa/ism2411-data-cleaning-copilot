# Reflection 

# What Copilot generated 
Copilot ended up generating most of the code I used for the cleaning process with some minor changes in order to adhere to the projects requirements. I prompted it simply by typing in a partial code. For example, I would type in def handle_missing and then it would complete the rest. And even give me the additional code that I needed. 

# What I modified 
I simplified steps and changed variables. For example, when copilot generated the "df.columns = ..." it added extra cleaning steps that weren't necessary for the assignment. I also changed the variables when I had errors with "qty" and "quantity".Those changes were needed so that the assignment doesn't become overcomplicated and doesn't produce errors. 

# What I learned 
I learned how important it is to check Copilot's code instead of accepting it automatically. It was extremely helpful for writing complicated code functions quickly, but it sometimes added unneccesary code and variables that can make errors. For example, copilot added extra steps to the cleaning process making it more complicated, so I had to think critically about my data. And even when I accepted their variable name of "qty" it created errors at the end of my project. This assignment showed me how Copilot can speed up work, but only when I guide it with clear comments.
